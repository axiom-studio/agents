# Axiom Studio Agents

Public agent definitions, skills, and team blueprints for Axiom Studio.

## Repository Structure

```
agents/         # Agent library definitions
skills/         # Reusable skill definitions
teams/          # Pre-built team blueprints
```

## Getting Started

Add this repository as a source in your Axiom Studio marketplace to discover and deploy agents, skills, and teams.

## Contributing

All contributions are welcome. Please open a pull request with your agent, skill, or team definition.
