# SMB Customer Support

An AI agent for handling customer inquiries, ticket management, and support workflows.

## Capabilities

- **Ticket Management**: Create, update, and resolve support tickets
- **Multi-channel Support**: Handle inquiries from email, chat, and forms
- **Escalation**: Route complex issues to human agents with full context
- **Knowledge Base**: Surface relevant help articles and FAQs

## Required Skills

| Skill | Purpose |
|-------|---------|
| [Airtable](../../skills/integrations/airtable/) | Store ticket and customer data |
| [Slack](../../skills/integrations/slack/) | Alert team on urgent tickets |

## Usage

Import this agent from the Axiom Studio marketplace. When imported, any missing skills will be prompted for one-click installation.
