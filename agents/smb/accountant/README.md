# SMB Accountant

An AI agent designed for small business bookkeeping, invoicing, and financial reporting.

## Capabilities

- **Bookkeeping**: Track income and expenses, categorize transactions
- **Invoicing**: Generate and send professional invoices
- **Expense Tracking**: Monitor business spending and flag anomalies
- **Financial Reporting**: Produce profit & loss, balance sheet, and cash flow summaries

## Required Skills

| Skill | Purpose |
|-------|---------|
| [Airtable](../../skills/integrations/airtable/) | Store and query financial records |
| [QuickBooks](../../skills/integrations/quickbooks/) | Sync with QuickBooks for accounting |
| [Slack](../../skills/integrations/slack/) | Send reports and alerts to team channels |

## Usage

Import this agent from the Axiom Studio marketplace. When imported, any missing skills will be prompted for one-click installation.
