# SMB Sales Assistant

An AI agent for managing leads, sales pipelines, and customer outreach for small businesses.

## Capabilities

- **Lead Management**: Capture, score, and track leads through the pipeline
- **Outreach**: Draft personalized emails and follow-up messages
- **Pipeline Tracking**: Monitor deal stages and forecast revenue
- **CRM Sync**: Keep customer data organized and up to date

## Required Skills

| Skill | Purpose |
|-------|---------|
| [Airtable](../../skills/integrations/airtable/) | Store lead and deal data |
| [Slack](../../skills/integrations/slack/) | Notify team of new leads and closed deals |

## Usage

Import this agent from the Axiom Studio marketplace. When imported, any missing skills will be prompted for one-click installation.
