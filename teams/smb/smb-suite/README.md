# SMB Operations Suite

A pre-built team of AI agents for small business operations.

## Members

| Name | Role | Agent | Skill Overrides |
|------|------|-------|-----------------|
| accountant | finance-lead | [SMB Accountant](../../agents/smb/accountant/) | QuickBooks: admin |
| sales-assistant | sales-lead | [SMB Sales Assistant](../../agents/smb/sales-assistant/) | — |
| support | support-lead | [SMB Customer Support](../../agents/smb/customer-support/) | — |

## Team Setup

1. Add `github.com/axiom-studio/agents` as a marketplace source
2. Navigate to **Teams** tab
3. Select **SMB Operations Suite**
4. Install any missing skills when prompted
5. Deploy the team to your workspace

All three agents will be created and configured to collaborate on daily SMB operations.
