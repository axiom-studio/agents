# Slack Integration

A skill that enables agents to send messages and interact with Slack channels.

## Node Types

- **slack-send-message**: Send a message to a Slack channel
- **slack-read-messages**: Read recent messages from a channel

## Configuration

Requires a Slack bot token with `chat:write` and `channels:read` scopes.

## Usage

Install via the Axiom Studio marketplace. Once installed, any agent that declares this skill as a dependency can use its node types in workflows.
