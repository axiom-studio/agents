# QuickBooks Integration

A skill that enables agents to manage invoices, expenses, and financial reports through QuickBooks.

## Node Types

- **quickbooks-invoice**: Create a new invoice in QuickBooks
- **quickbooks-report**: Retrieve financial reports (P&L, balance sheet, cash flow)

## Configuration

Requires QuickBooks OAuth credentials.

## Usage

Install via the Axiom Studio marketplace. Once installed, any agent that declares this skill as a dependency can use its node types in workflows.
