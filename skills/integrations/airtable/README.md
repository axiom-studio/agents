# Airtable Integration

A skill that enables agents to read from and write to Airtable bases.

## Node Types

- **airtable-read**: Fetch records from an Airtable table with optional filtering
- **airtable-write**: Create or update records in Airtable

## Configuration

Requires an Airtable personal access token with appropriate base permissions.

## Usage

Install via the Axiom Studio marketplace. Once installed, any agent that declares this skill as a dependency can use its node types in workflows.
